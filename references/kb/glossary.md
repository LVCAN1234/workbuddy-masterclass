# 概念术语库 (Glossary)

> 教 Agent 课程的核心概念权威定义。每条：定义 → 通俗类比 → 易错点 → 关联课。
> 生成课程 / 口播素材时优先引用此处，避免凭记忆编造。

## Agent（智能体）
- 定义：能感知环境、做决策、调用工具并完成任务的 AI 系统，而不只是「对话」。
- 类比：Chatbot 是只会说话的大脑；Agent 是长了手脚、还能自己做决定的助理。
- 易错点：Agent ≠ 更聪明的 Chatbot。本质是「能不能真的去执行操作」。
- 关联课：第 1 课（Agent vs Chatbot）、第 3 课（Agent 四件套）

## LLM（大语言模型）
- 定义：基于海量文本训练出的神经网络，核心能力是「根据已有文字，预测下一个最可能出现的词（Token）」。
- 类比：一个读过无数书、靠「文字接龙」生成内容的大脑。
- 易错点：LLM 本身不会「查资料 / 执行」，它只生成 Token；「执行」靠 Agent 的工具。
- 关联课：第 2 课（LLM 工作原理）

## Token（词元）
- 定义：文本被拆分后的最小处理单位。中文常按字 / 词片切分，英文按词根 / 子词。
- 类比：乐高积木的最小块——模型用这些块拼出回答。
- 易错点：计费、上下文窗口、速度都按 Token 算，不是按「字数」。
- 关联课：第 2 课

## 上下文窗口 (Context Window)
- 定义：模型一次能「看到」的 Token 总量上限（含输入 + 输出）。
- 类比：短期记忆容量——超出就「忘了」前面的内容。
- 易错点：长文档 / 长对话会撑爆窗口，需要摘要或分段。
- 关联课：第 2 课

## Temperature（温度）
- 定义：控制生成随机性 / 创造性的参数。高 = 更发散，低 = 更保守确定。
- 易错点：不是「模型智商」。写代码 / 事实类用低温，创意类用高温。
- 关联课：第 2 课

## 幻觉 (Hallucination)
- 定义：模型生成看似合理但事实错误的内容。
- 易错点：模型「自信地胡说」，不会主动标错。需靠工具 / 检索核实。
- 关联课：第 2 课

## Function Calling（函数调用 / 工具调用）
- 定义：LLM 用结构化 JSON（name + 参数）请求调用外部工具；LLM 负责「决策调哪个、传什么」，系统负责「执行」。
- 类比：玻璃房里的厨师——LLM 只会写菜谱（生成 Token），真要炒菜（执行）得让外面的助手动手。
- 易错点：LLM 不执行工具，它只「提议」；参数格式错会导致调用失败。
- 关联课：第 4 课

## 工具 / Tools
- 定义：Agent 可调用的外部能力（查天气、跑代码、读文件、调 API）。
- 关联课：第 3 课（Agent 四件套）、第 4-5 课

## ReAct
- 定义：推理 (Reasoning) + 行动 (Acting) 循环框架：思考 → 调工具 → 看结果 → 再思考。
- 关联课：第 5 课（回复解剖）、第 8 课（Agent Loop）

## 记忆 / Memory
- 定义：跨对话保存信息的能力。三层：云记忆（profile + 历史检索）、用户级本地、工作区级。原则：只追加、不覆盖。
- 易错点：记忆不是数据库，是「注入上下文」。写错会污染后续。
- 关联课：第 7 课、第 14 课

## System Prompt（系统提示）
- 定义：出厂时设定的身份与规则，决定 Agent「是谁、能做什么」。
- 类比：出厂身份证。
- 易错点：防篡改，用户对话无法覆盖核心设定。
- 关联课：第 6 课

## Skill（技能）
- 定义：把「多工具 + 领域知识 + 工作流」打包成可复用单元。分用户级（全局）和项目级（仅本项目）。
- 易错点：Skill 是「怎么做一件事」的封装，不是「知识库」。
- 关联课：第 10 课

## MCP（模型上下文协议）
- 定义：连接外部系统（飞书 / 钉钉 / 腾讯文档等）的标准协议，类似「USB 插头规格」。
- 易错点：需手动授权；按需调用，不是持续后台同步。
- 关联课：第 12 课、第 16 课

## 自动化 / Automation
- 定义：按时间或触发条件自动执行任务（定时循环 / 一次性）。
- 易错点：依赖 WorkBuddy 在线；不是操作系统级 cron。
- 关联课：第 13 课

## 专家 / Experts
- 定义：特定领域的专业人格（「谁来做」），可绑定 Skill。
- 关联课：第 11 课

## 工作模式 (Work Mode)
- 定义：Craft（直接干）/ Plan（先规划后执行）/ Ask（只答不做）。
- 关联课：第 9 课
