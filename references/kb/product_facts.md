# WorkBuddy 产品事实库 (Product Facts)

> 来自官方文档 + 课程实测。生成课程 / 口播素材时引用，避免编造产品功能。
> 来源：https://www.codebuddy.cn/docs/workbuddy/Overview 及课程第 0 课实测。

## 产品定位
腾讯出品的**全场景 AI 办公工作台**：说出要求 → 开始执行 → 交付完整成果。深度连接腾讯办公生态。

## 核心能力（官方）
1. 理解自然语言：一句话下达任务，无需复杂操作
2. 自主规划执行：自动拆解、规划、执行
3. 多模态任务：文档 / 表格 / PPT / 数据分析等
4. 本地文件操作：可读取授权文件夹批量处理

## 与传统 AI 对话的区别
能实际执行任务、自动操作本地文件、处理多步骤复杂任务、交付可验收结果（而非只给文字建议）。

## 界面三大区
- 左侧边栏：任务列表 + 空间列表
- 中间对话区：标题栏 + 消息 + 输入框
- 右侧结果区：概览 / 产物 / 浏览器 / 变更 四视图

## 任务 vs 空间
- 任务：一次具体执行（「写周报」）
- 空间（工作空间）：一组相关任务的集合，通常对应一个项目文件夹
- 关系：一个空间下多个任务

## 任务状态
进行中 / 已完成 / 失败 / 待处理 / 规划中 / 已归档

## 输入框功能区
工作空间选择、@引用、粘贴截图 (Ctrl/Cmd+V)、上传文件、技能选择 (+) 、工作模式切换 (Craft/Plan/Ask)

## 模型清单与算力倍率（右上角数字 = 消耗倍率，越高越贵）
- Auto：自动选择（默认）
- Hy3：0.0x，夜间加速，限时免费
- GLM-5.2 / 5.1：0.79x
- GLM-5v-Turbo：0.95x，带视觉
- MiniMax-M3：0.25x，低成本
- Kimi-K3：1.62x，复杂任务强
- Kimi-K2.7-Code：0.57x，代码
- Kimi-K2.6：0.52x，通用
- Deepseek-V4-Flash：0.05x，高性价比
- Deepseek-V4-Pro：0.13x，高性价比

## 结果区四视图
概览（文件 / 浏览器 / 变更总览）、产物（生成的文件）、浏览器（预览网页 / 本地 Web 应用）、变更（文件改动）

## 关键限制与事实
- 自动化依赖 WorkBuddy 在线运行
- MCP 需手动授权，按需调用（非持续同步）
- 二进制依赖（Chromium / whisper 等）在沙箱临时区，新对话可能被清理 → 课程视频流水线需 bootstrap 固化（见 cases.md）
- 本地数据路径：`~/.workbuddy/`（记忆、技能、配置）；项目级 `.workbuddy/`（项目记忆、技能）
- 跨对话框持久的是：代码、脚本、长期记忆、项目目录；二进制依赖需主动固化

## 适用场景（官方）
文档生成、数据分析、PPT / 报告、深度研究、邮件 / 周报、批量文件处理
