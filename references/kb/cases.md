# 实战案例与常见坑 (Cases)

> 可复用工作流 + 排错经验。每条：场景 → 做法 → 坑 → 结论 / 可复用性。

## 案例 1：课程口播视频流水线（course-to-video skill）
- 场景：把「口播素材 HTML 动画」+「用户出镜口播视频」对齐合成课程视频。
- 做法：渲染动画 → whisper ASR → 触发词驱动对齐（B 标准：切点准 + 段内不拉伸）→ 圆形画中画合成 → 兼容封装。
- 坑：
  - HEVC 口播视频 whisper 解不了 → 先 ffmpeg 抽 WAV (16kHz mono) 再 ASR。
  - Chromium / playwright 装在沙箱临时区，新对话框被清 → 「浏览器找不到 / 插件找不到」。
  - 慢转码 → 改 veryfast + 输入定位 (-ss 前置) 切段。
  - 12800 tbn 封装双击打不开 → 用 15360 tbn + faststart。
- 结论：依赖必须固化进 skill 持久区（bootstrap.py 自举 + deps_paths.json）；已封装为 course-to-video skill，养生 / 健身等口播课通用（仅换内容 HTML + 触发词）。
- 可复用性：高。

## 案例 2：GEO 诊断报告（腾讯文档交付）
- 场景：用户要求 GEO 诊断报告以 Word 在线文档发到腾讯文档。
- 坑：腾讯文档连接器当前为断开状态，未直接打通。
- 结论：需先连接腾讯文档连接器（用户侧操作）；交付形态建议「在线文档」。
- 可复用性：中（依赖连接器状态）。

## 案例 3：跨领域课程迁移（养生 / 健身课）
- 场景：把「教 Agent」课程的方法论迁移到养生 / 健身口播课。
- 做法：workbuddy-masterclass（Agent 内容）不适用 → 需重做内容；teaching-methodology + course-to-video 骨架完全复用（换内容 HTML + 触发词）。
- 结论：内容层与骨架层解耦——内容随主题重做，方法 / 流水线通用。
- 可复用性：高（任何口播类课程）。

## 案例 4：通用 Skill vs 自建 Skill 决策
- 场景：新需求不确定用通用还是自建。
- 做法：多数需求先用 SkillHub / ClawHub 通用 skill；仅两种情形自建——① 通用差一口气且自己反复遇到；② 有独有流程 / 规范 / 数据格式。
- 结论：通用能解决就不自建（定制更贴实际但成本高）。
- 可复用性：高（决策原则）。

## 案例 5：阿里云 ECS 部署静态网站全链路（建站上云实战）
- 场景：用 WorkBuddy 生成静态网站后，部署到阿里云 ECS 并绑定域名，让外网可访问（真实案例：谋仕AI 官网 geomoushi.com）。
- 做法：SSH 免密连服务器 → yum 装 Nginx → scp 传网站文件到 /var/www/moushi/ → 写 /etc/nginx/conf.d/moushi.conf 配域名 → 注释主配置默认 server 块避免冲突 → 从公网 IP + 域名双验证。
- 坑：
  - 阿里云安全组默认只放行 22 端口，部署网页必须提醒用户控制台**放行 80（HTTP）/ 443（HTTPS）**，否则外人打不开——且本地 127.0.0.1 通 ≠ 外网通，必须公网 curl 验证。
  - SSH 密钥文件（.pem）放本机固定文件夹，WorkBuddy 用 `-i 密钥.pem` 连接；密码会进命令记录，推荐免密。
  - Nginx 主配置自带默认 server 块，需注释掉避免与自定义站点冲突（nginx -t 会报冲突）。
- 结论：环境 / 文件 / 配置 Agent 都能干，但「云控制台安全组」和「域名解析 A 记录」这两步是人工在网页点的，Agent 改不了——交付前必须明确交给用户。
- 关联课：第 21 课建站上云实战。
- 可复用性：高（任何静态站上云）。
